# 汉王 N10 Plus 无线手写板

把汉王 N10 Plus 电纸书当作电脑的手写板使用（白板模式）。

## 原理

设备开启无线调试后，通过 adb 读取笔输入节点 `/dev/input/event7`（`pen_touch`）的
`getevent` 事件流：坐标 0–1872 × 0–1404（与屏幕 1:1），压感 0–1024，约 300Hz 上报。
电脑端后台线程解析事件流并实时绘制到 pygame 窗口，断线自动重连。

## 使用

```bash
# 1. 设备开启无线调试，配对并连接（端口以设备显示为准）
adb pair <设备IP>:<配对端口>
adb connect <设备IP>:<端口>

# 2. 启动（用 uv 管理 Python 环境）
uv run python main.py
```

- 笔尖书写，压感映射笔迹粗细；**笔尾翻转让笔尖朝下即为橡皮擦**
- **笔迹平滑**：`M` 键或工具栏切换 关/轻/中/强（默认 轻，EMA 滤波，快速斜线不抖）
- **压感曲线**：PCHIP 单调三次曲线，`P` 键切换 柔软/适中/硬笔/自定义；`U` 或工具栏"曲线编辑"打开可视化编辑器，直接拖拽控制点
- **对象切割橡皮**：橡皮扫过的笔画在相交处断开，只删被扫到的部分，其余保留；拖动时有实时视觉反馈
- **圈选擦除**：用笔尾画一个闭合的圈（缺口小于圈直径 30% 自动识别），圈内整笔删除；不闭合则退回切割橡皮
- **操作历史**：画/切割/圈选/清空全部入栈，`Z` 撤销、`Shift+Z` 重做
- **旋转**：`R` 键或工具栏"旋转"按钮循环 0/90/180/270°，竖着拿板子也没问题
- **压感手感**：`[` `]` 调最细倍率，`-` `=` 调最粗倍率，HUD 实时显示；也可用 `--min-mult --max-mult --curve --smooth` 启动参数
- 底部工具栏可点击：4 色 / 4 档笔宽 / 撤销 / 清空 / 保存 / 旋转 / 曲线 / 平滑 / 橡皮切换
- 快捷键：`Z` 撤销 · `C` 清空 · `S` 保存 PNG · `E` 橡皮/画笔 · `1-4` 颜色 · `R` 旋转 · `P` 曲线 · `M` 平滑 · `[` `]` `-` `=` 粗细
- 笔迹以设备坐标存储，窗口拖拽缩放后重绘不失真
- 建议在电纸书设置中关闭自动锁屏，否则休眠后事件会停

## 参数

```
--serial         adb 设备序列号（默认自动检测，优先 IP 连接）
--width          窗口宽度，默认 1123
--min-pressure   低于此压感不画线（过滤悬空噪声），默认 50
--pen-size       基准笔宽，默认 6
```
